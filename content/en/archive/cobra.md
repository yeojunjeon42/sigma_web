A snake-like articulated robot that propels itself using anisotropic ventral friction vectors generated by unidirectional belly scales and synchronized multi-servo undulation. Controlled via Bluetooth from an Android smartphone, COBRA won Silver at the 2013 ECE Electronics Fair.

- Used daisy-chained DYNAMIXEL actuators to minimize external wiring and navigate narrow spaces
- Implemented wireless control via Bluetooth and a smartphone software controller
- Displayed real-time robot joint status in a GUI using DYNAMIXEL feedback telemetry
- Integrated infrared distance sensors for autonomous obstacle detection and avoidance
