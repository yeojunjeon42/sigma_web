## Setting a GOAL

원격 조작

손의 기울기를 이용한 신호 전송 및 수신

자유로운 움직임

전후좌우/좌우회전/대각선 움직임

안정성 및 확장성

통신과 전원 공급의 안정성, 입/출력 장치의 응용 가능성

## 프로토타입 251114

- 주 재료 : 빵판 / 종이 / 양면테이프 / 절연테이프
- 사용한 IC : Arduino Nano / HC-06 / L9110 / 6V 통합전원
- 주 기능 : 노트북과 블루투스 연결 제어 / 전후좌우 이동

## 1차 성능 개량 251219

- 주 재료 : 빵판 / PLA 하부면 / 양면테이프 / 절연테이프
- 사용한 부품 : Arduino Nano / HC-06 / L9110 / 6V 전원 / 6V 모터전원 / LED
- 개량된 기능 : 콘솔과 블루투스 연결 제어 / 전원분리 / 주행모드 별 LED
- 콘솔 사용한 부품 : Xiao / HC-05 / GY-9250 / 4.5V 전원 / 버튼
- 콘솔 기능 : 블루투스 연결 제어 / 기울기 기반 방향 제어 / 주행모드 버튼

## 2차 성능 개량 251222

- 사용한 부품 : Arduino Nano / HC-06 / L9110 / 릴레이 / 6V 전원 / 6V-12V 가변 모터전원 / LED / HC-SR04
- 개량된 기능 : 가변 모터전원으로 속도 조절 / 초음파 충돌회피
- 콘솔 개량된 기능 : 기울기 기반 속도 조절

## 3차 성능 개량 260122

- 주 재료 : PCB / PLA 외관
- 사용한 부품 : Arduino Nano / HC-06 / TB6612 / 릴레이 / 6V 전원 / 6V-12V 가변 모터전원 / 주행등 LED / 방향지시등 LED / 정지등 LED / 후진등 LED
- 개량된 기능 : 개량된 모터 드라이버 / 풀 LED
- 콘솔 사용한 부품 : Xiao / HC-05 / GY-9250 / 4.5V 전원 / 버튼 / SZH-EK056 / 스위치
- 콘솔 개량된 기능 : 제어모드 버튼 / 조이스틱기반 제어 / 부스터 버튼 / 전원스위치
